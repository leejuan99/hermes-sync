# Getting a Telegram Bot Token

1. Open Telegram and chat with @BotFather.
2. Send the command `/newbot` and follow the prompts.
3. Choose a name and username for your bot (username must end in `bot`).
4. BotFather will generate a token like `123456789:AAABbbCcccDddeEeeFGhhhIIiiJJjjKKk`.
5. Copy the token and keep it secure.

Never share your token publicly or commit it to version control.
