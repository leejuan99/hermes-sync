# Composio Social Media Automation

## When to Use
Use when you want to automate social media posting from a WordPress site using Composio for OAuth/account management, n8n for workflow orchestration, and AI for content generation.

See references/composio-toolkits.md for toolkits.
See templates/n8n-publisher.json for n8n workflow.
See scripts/test-composio-connection.sh for test script.
