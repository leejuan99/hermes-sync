# How to Find Your GA4 Property ID

1. Sign in to Google Analytics (https://analytics.google.com).
2. In the left‑hand menu, click **Admin** (gear icon).
3. In the **Property** column, ensure the correct property is selected.
4. Click **Property Settings**.
5. The **Property ID** is displayed as a numeric value (e.g., `123456789`).
6. For MCP usage, prefix it with `properties/` → `properties/123456789`.

## Tip
You can also see the ID in the URL when viewing the property: `.../p/123456789/settings`.
